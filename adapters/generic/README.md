# Generic Adapter

Phase 4 implements the generic adapter as a deterministic single-file bundle generated by `tools/build_adapters.py`.

Output:

```text
dist/adapters/generic/QSOL-SUBSTRATE.txt
```

The file embeds the complete canonical projection plus exact substrate snapshot, source commit, canonical SHA-256, projection SHA-256, adapter ID, and adapter spec version.

Use it when the target system has no dedicated integration.

The generic adapter is transport only. It may wrap or serialize canonical records, but it must not add, delete, reinterpret, or promote substrate facts.

See `docs/ADAPTERS.md` for the build and validation contract.
