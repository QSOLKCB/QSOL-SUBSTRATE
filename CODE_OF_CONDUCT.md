# Code of Conduct

QSOL-SUBSTRATE welcomes technical discussion, corrections, provenance improvements, adapter work, and reproducibility research.

Participants are expected to engage in good faith, critique claims and implementations rather than people, avoid harassment or discriminatory conduct, respect privacy boundaries, and avoid publishing private information in issues or pull requests.

Because this repository is designed for public machine ingestion, contributors should take particular care not to use examples that expose secrets, private correspondence, personal data, or protected context.

Maintainers may edit, hide, lock, or remove contributions that create security, privacy, legal, or community-safety problems.
